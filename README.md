# coupang-store-tool

쿠팡 판매자를 위한 **상품 카탈로그 점검 + 광고 분석** Chrome 확장 프로그램입니다.
WING과 쿠팡 광고센터에서 이미 로그인한 화면의 데이터를 읽어, 매일 상품 상태를 점검하고 광고가 손해인지 판단합니다.

> ⚠️ **비공식 도구입니다.** 쿠팡(Coupang)과 관련이 없으며 쿠팡이 제공하거나 보증하지 않습니다.
> 쿠팡이 공개하지 않은 화면 내부 요청을 사용하므로, 쿠팡 화면이 바뀌면 동작하지 않을 수 있습니다.
> 사용 전 쿠팡 판매자·광고 이용약관을 확인하고, 사용에 따른 책임은 사용자에게 있습니다.

- 현재 버전: **0.7.2** (변경 내용: [CHANGELOG.md](CHANGELOG.md))
- 화면·설명: 한국어
- 만든 사람 블로그: **[Toolbox Notes](https://toolboxnotes.com/ko/)** — 사용 후기·문의·다른 도구 소개

## 무엇을 해 주나요

### 1. 상품 점검 (WING)
- 판매 중인 상품의 **옵션별 노출 상태**를 한 번에 모아 봅니다.
  - 노출 제한, 아이템위너 아님(타사 / 내 다른 옵션), 품절, 속성 오류, 브랜드 없음 등
  - **노출상품ID 변경** = 내 옵션이 다른 판매자 상품에 잘못 매칭됐을 가능성
  - **옵션 분리** = 내 옵션들이 여러 상품 페이지로 나뉘어 있는 경우
- 지난 점검과 비교한 **변경 내역**(새 문제·해결됨·노출상품ID 변경)
- 문제 유형·옵션별 **무시** 기능 (무시 목록에서 해제 가능)
- 매칭 분리 / 옵션 결합 **온라인 문의 자동 입력** (확인·첨부·제출은 직접)
- 매일 자동 점검 + 알림

### 2. 광고 분석 (쿠팡 광고센터)
- 캠페인별 광고비·매출·ROAS·클릭률·전환율·**예산 소진율**
- 마진율로 **손익분기 ROAS** 계산 (캠페인별 마진율 지정 가능) → 손해 보는 캠페인 표시
- **광고 중인 문제 상품**: 노출 제한·품절·아이템위너 아닌 상품에 광고비가 나가고 있는지
- AI 스마트 광고 vs 나머지 캠페인 비교, 제외 키워드·제외 상품 현황
- 광고 보고서(엑셀) 업로드 → **전환 없는 키워드** 찾기 → 제외 키워드 추가안
- **수정사항**: 진단 결과로 일예산·목표 ROAS·ON/OFF 변경안 생성 → 확인 후 적용 → **변경 효과**(적용 전후 비교) 확인
- 매주 광고 점검 알림

### 3. 키워드 트렌드 (WING 쿠팡 인기 상품 검색)
- 내 상품 카테고리의 인기 검색어, 키워드별 상위 상품 조회수·가격·리뷰, **내 상품 순위**
- 내 상품이 순위 밖이거나 제외 키워드에 막힌 인기 키워드 추천

### 4. 요약 「오늘 할 일」
상품·광고에서 지금 처리할 일을 모아 보여 주고, 누르면 해당 화면으로 이동합니다.

## 설치 방법

Chrome 웹 스토어에 등록되어 있지 않으므로 **개발자 모드로 직접 설치**합니다.

### 방법 A. 압축 파일로 설치 (권장)
1. **[최신 버전 다운로드 (coupang-store-tool-extension.zip)](https://github.com/toolboxnotes/coupang-store-tool/releases/latest/download/coupang-store-tool-extension.zip)** — 링크는 항상 최신 버전 파일입니다. 특정 버전이 필요하면 [Releases](../../releases)에서 `coupang-store-tool-extension-v버전.zip`을 받습니다.
2. 압축을 풉니다. (예: `D:\tools\coupang-store-tool-extension`)
3. Chrome 주소창에 `chrome://extensions` 입력
4. 오른쪽 위 **개발자 모드** 켜기
5. **「압축해제된 확장 프로그램을 로드합니다」** → 2번에서 푼 폴더 선택
6. 툴바의 퍼즐 아이콘 → **coupang-store-tool** 고정(📌) → 아이콘을 누르면 오른쪽에 사이드 패널이 열립니다.

### 방법 B. 저장소 전체를 내려받아 설치
1. 이 페이지 위쪽 초록색 **Code → Download ZIP** 으로 내려받아 압축을 풉니다. (또는 `git clone https://github.com/toolboxnotes/coupang-store-tool.git`)
2. `chrome://extensions` → 개발자 모드 → 「압축해제된 확장 프로그램을 로드합니다」 → 압축을 푼 폴더 안의 **`extension` 폴더** 선택

### 업데이트
새 버전 파일로 폴더 내용을 바꾼 뒤 `chrome://extensions` 에서 이 확장의 **새로고침(↻)** 버튼을 누릅니다. 저장된 점검 결과·설정은 유지됩니다.

### 필요한 것
- Chrome (또는 Chromium 기반 브라우저, 사이드 패널 지원 버전)
- 쿠팡 **WING** 로그인 (상품 점검·키워드 트렌드)
- 쿠팡 **광고센터** 로그인 (광고 분석) — 로그인 화면에서 「쿠팡 마켓플레이스 & 로켓그로스 판매자 → 로그인하기」
- 별도의 API 키는 필요 없습니다.

## 사용 방법

### 처음 한 번
1. Chrome에서 **WING에 로그인**한 상태로 사이드 패널을 엽니다.
2. 위쪽 **「지금 점검」** → 상품 수에 따라 몇 분 걸립니다. (WING 탭이 없으면 백그라운드 탭을 열었다가 닫습니다)
   - 점검 중 **「중지」** 를 누르면 지금 단계가 끝나고 멈춥니다. 나중에 **「이어서 점검」** 으로 계속하거나 **「처음부터 다시」** 를 누르세요. 로그인 만료·차단·브라우저 종료로 끊겨도 진행 상황이 저장되어 이어서 점검할 수 있습니다 (12시간 보관).
3. **「광고」 탭 → 마진율 입력 → 「광고 점검」** → 광고센터 화면으로 이동해 점검합니다.
   - 마진율 = (판매가 − 원가 − 쿠팡 수수료 − 배송비) ÷ 판매가. 광고비를 빼기 **전** 이익률입니다.
4. **「요약」 탭의 「오늘 할 일」** 부터 확인하세요.

### 화면 구성
| 탭 | 내용 |
|---|---|
| **요약** | 오늘 할 일, 문제 유형별 개수 |
| **상품** | 「문제 목록」: 처리할 문제, 무시 목록, 링크(WING 수정·쿠팡 상품·온라인 문의) / 「변경 내역」: 지난 점검 대비 바뀐 내용 |
| **광고** | 「캠페인」: 성과·진단·광고 중인 문제 상품·AI 스마트 비교 / 「키워드」: 광고 보고서 분석 / 「수정사항」: 변경안·적용·변경 효과 |
| **키워드 트렌드** | 내 카테고리 인기 검색어와 내 상품 순위 |
| **설정** | 자동 점검 시각, 알림, 요청 간격(페이지 간 대기·광고센터 요청 간격), 로컬 데이터 삭제 |

### 상품 문제 처리
- **노출상품ID 변경 / 타사 아이템위너**: 「상품 → 문제 목록」에서 「분리 요청 문의 작성」 → 온라인 문의 양식이 자동으로 채워집니다. 내용 확인, 체크박스, 첨부, 제출은 직접 합니다.
- **옵션 분리**: 「결합 요청 문의 작성」으로 같은 방식.
- **노출 제한·속성 오류**: 「WING 수정 ↗」 버튼으로 해당 상품 수정 화면을 엽니다.
- 처리하지 않을 문제는 「무시」 (옵션별 또는 유형 전체).

### 광고 수정사항
1. 「수정사항 → 진단 결과로 변경안 만들기」
2. 변경안마다 이유가 표시됩니다. 값은 직접 고칠 수 있습니다.
3. 적용할 항목을 선택 → **「선택 항목 적용」** → 확인 창에서 동의해야만 광고센터에 반영됩니다. (일예산·목표 ROAS·ON/OFF)
4. 제외 키워드는 자동 적용하지 않습니다. 「복사 + 편집 화면 열기」 후 직접 붙여넣고 저장하세요.
5. 적용 후 7일이 지나면 기간 「최근 7일」로 광고 점검 → 「적용 기록 · 변경 효과」에서 개선/악화를 확인합니다.

변경안 기준(목표 ROAS·일예산을 어떻게 판단하는지)은 [docs/광고-변경안-기준.md](docs/광고-변경안-기준.md)를 참고하세요.

> 💡 직접 적용 기능은 처음 사용할 때 **중요하지 않은 캠페인 1개**로 먼저 시험하고, 광고센터에서 반영됐는지 확인하세요.

### 광고 키워드 분석
1. 광고센터 → 광고보고서 → 「매출 성장 광고 보고서」에서 기간·캠페인을 골라 보고서를 만들고 엑셀을 내려받습니다.
2. 「광고 → 키워드」에서 파일을 올립니다.
3. 전환 없이 광고비만 쓴 키워드 → 「제외 키워드 추가안 만들기」.

## 요청 속도와 차단

WING·광고센터는 짧은 시간에 요청이 많으면 잠시(약 30분) 막습니다. 이 확장은 다음과 같이 요청을 줄입니다.
- 요청 사이 간격: WING 2초, 키워드 트렌드 3초 이상, 광고센터 4초 (모두 불규칙, 설정에서 조정)
- 광고 점검 후 3분 동안 재점검 금지
- 재사용: 광고그룹 상세 6시간, 광고 상품 목록 7일, 키워드 트렌드 24시간
- 차단되면 잠시 쉬고 1번만 다시 시도 → 그래도 막히면 중단하고 그때까지 결과를 저장

막혔다는 안내가 나오면 30분쯤 뒤 다시 시도하세요.

## 데이터와 개인정보

- 모든 점검 결과와 설정은 **이 PC의 Chrome 저장소(chrome.storage.local)에만** 저장됩니다. 외부 서버로 보내지 않습니다.
- 쿠팡 광고센터 데이터는 외부 공개·제3자 제공이 금지되어 있습니다. 내보낸 CSV 등을 공유할 때 주의하세요.
- 「설정 → 로컬 데이터 삭제」로 저장된 점검 결과를 지울 수 있습니다.
- 사용하는 권한: `storage`, `unlimitedStorage`, `alarms`, `notifications`, `sidePanel`, `scripting`, `tabs`
  접근 사이트: `wing.coupang.com`, `advertising.coupang.com`, `helpseller.coupangcorp.com`

## 폴더 구조

```
extension/            Chrome 확장 프로그램 (이 폴더를 로드)
  manifest.json
  background.js       점검 실행·알림·광고 적용
  sidepanel.*         사이드 패널 화면
  ads-panel.js        광고 탭
  trends-panel.js     키워드 트렌드 탭
  todo-panel.js       요약 「오늘 할 일」
  content/            온라인 문의 자동 입력
  lib/                점검·분석 로직 (core / adcore / trendcore, 화면 내부 요청 wing / ads / adsWrite / trends)
  vendor/             SheetJS (엑셀 읽기)
  tests/              단위 테스트
docs/                 개발 목록, 광고 변경안 기준
server/               서버 버전 (보류)
```
