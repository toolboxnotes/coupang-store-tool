# coupang-store-tool v0.7.1 (1단계: 상품 점검)

## 설치 (개발자 모드)
1. 이 `extension` 폴더가 확장 프로그램 본체입니다 (이동·삭제하지 마세요).
2. Chrome 주소창에 `chrome://extensions` 입력 → 오른쪽 위 「개발자 모드」 켜기.
3. 「압축해제된 확장 프로그램을 로드합니다」 클릭 → `coupang-store-tool\extension` 폴더 선택.
4. 툴바의 퍼즐 아이콘에서 coupang-store-tool을 고정하면, 아이콘 클릭 시 오른쪽 사이드 패널이 열립니다.
5. 코드를 수정한 뒤에는 `chrome://extensions`에서 새로고침(↻) 버튼을 누르세요.

## 사용 방법
1. Chrome에서 WING(wing.coupang.com)에 로그인합니다.
2. 패널에서 「지금 점검」을 누릅니다. WING 탭이 없으면 백그라운드 탭을 잠시 열어 상품 목록을 읽고 자동으로 닫습니다.
3. 「요약」에서 문제 수를 확인하고, 항목을 누르면 「문제 목록」으로 이동합니다. CSV로 내보내 엑셀에서 열 수 있습니다.
4. 카드 아래 버튼으로 실제 쿠팡 상품 페이지, 쿠팡 검색 결과, WING 수정 화면을 새 탭으로 열 수 있습니다. 처리 대상 카드는 빈 곳을 누르면 선택/해제됩니다.
5. 확인했지만 처리하지 않을 문제는 카드의 「무시」(옵션의 현재 문제 전부) 또는 태그의 ✕(문제 하나)로 무시할 수 있습니다. 같은 옵션의 같은 문제는 이후 점검에서도 계속 무시되며, 「문제 목록 → 무시 목록」에서 따로 확인하고 해제할 수 있습니다.
   - 일괄 무시: 카드의 체크박스 또는 「전체 선택」 후 「선택 N건 무시」. 문제 유형 필터를 고르고 전체 선택하면 그 유형만 한 번에 무시됩니다.
   - 유형 전체 무시: 문제 유형 필터를 고른 뒤 「○○ 항상 무시」 → 모든 상품(이후 새 상품 포함)에 적용, 무시 목록의 「유형 무시 규칙」에서 해제.
6. 「변경 내역」은 옵션 분리 목록이 아니라 지난 점검 대비 바뀐 내용입니다 (옵션 분리 목록은 「문제 목록 → 옵션 분리됨」 필터). 각 카드에서 무시, 문제 목록에서 보기, 분리/결합 요청서 복사를 할 수 있습니다.
   「변경 내역」은 지난 점검 대비 새 문제 / 해결됨 / 노출상품ID 변경(매칭·결합 의심)을 보여줍니다.
7. 설정에서 매일 자동 점검(Chrome이 켜져 있을 때), 알림, 데모 모드를 켤 수 있습니다.

## 진단 항목
쿠팡이 WING에 내려주는 판정 데이터를 그대로 사용합니다. 판매중지 상품·판매불가 옵션은 기본 제외.

| 문제 | 판정 근거 |
|---|---|
| 노출제한 | 노출 상태 BUP·BAP_SUPPRESSION / suppressed |
| 상품정보 수정필요 | ATTRIBUTE_VIOLATION, 옵션 구성 오류(NO_VA_V2), 누락된 필수 속성 |
| 옵션 필수속성 누락 | MISSING_OPTION_TABLE_ATTR / MOTA_V2 (노출 낮음) |
| GTIN/모델번호 누락 | 위반 유형 MPN (노출 낮음) |
| 아이템위너 아님(타사) | 노출 상태 ITEM_LOSER |
| 자사 상품에 위너 뺏김 | ITEM_LOSER + buyboxLoserBySellerSelf |
| 옵션 분리됨 | 같은 등록상품의 옵션이 서로 다른 노출상품ID (상세 수집 필요) |
| 노출상품ID 변경 | 지난 스냅샷과 비교 (상세 수집 필요) |
| 브랜드 누락, 재고 0 | 상품 데이터 |

## 온라인 문의 자동 입력 (분리 / 결합 요청)
- 「아이템위너 아님(타사)」 카드 → **「분리 요청 문의 작성」**: 상이한 상품과 잘못 매칭된 옵션의 분리 요청
- 「옵션 분리됨」「자사 상품에 위너 뺏김」 카드 → **「결합 요청 문의 작성」**: 여러 상품 페이지로 나뉜 옵션의 결합 요청
- 버튼을 누르면 쿠팡 판매자 온라인 문의 작성 화면(요청 유형 「[마켓플레이스/로켓그로스] 상품 정보가 잘못 노출되고 있습니다.」)이 열리고
  제목·설명·옵션명·상품 ID·상품명·판매자 코드가 자동 입력됩니다. 요청서는 클립보드에도 복사됩니다.
- 제출 전에 직접 하세요: ① 설명의 「상이한 점」 작성(분리 요청) ② 상단 확인 체크박스 ③ 증빙 사진·상표권 첨부 ④ 제출
- 쿠팡 안내에 따라 옵션ID가 여러 개면 옵션마다 따로 문의하세요.

## 수정 바로가기
- 「WING 수정」: WING 상품 수정 화면(등록상품 단위)을 바로 엽니다. 카드에 표시된 상세 사유(누락 속성, GTIN/모델번호 등)를 참고해 수정하세요.

## 광고 분석 (「광고」 탭)
광고센터(advertising.coupang.com)에 로그인되어 있어야 합니다. 로그인 화면이 나오면 「쿠팡 마켓플레이스 & 로켓그로스 판매자 → 로그인하기」.
기간(7/14/30일)과 **마진율**을 정하고 「광고 점검」 → 광고센터 화면으로 자동 이동한 뒤 점검합니다 (로그인 화면이면 로그인하는 대로 이어서 점검, 최대 3분) (손익분기 ROAS = 100 ÷ 마진율 × 100, 마진 30% → 333%).

광고센터는 요청이 빠르면 잠시 막히므로 요청 간격 4초(설정에서 변경), 점검 후 3분 동안 재점검 금지, 광고그룹 상세는 6시간 재사용·한 번에 20개입니다. 차단되면 1분 쉬고 1번 재시도한 뒤 중단하고 지금까지 결과를 저장합니다.

### 캠페인
캠페인별 광고비·매출·ROAS·클릭률·전환율·CPC, 제외 키워드 수·제외 상품 수·노출 상태 알림, 진단과 제안.
| 진단 | 기준 |
|---|---|
| 손익분기 미달 | 광고비 1만원 이상, ROAS < 손익분기 ROAS |
| 전환 없는 광고비 | 광고비 1만원 이상, 전환 주문 0 |
| 목표 ROAS 미달 | ROAS < 목표 ROAS × 80% |
| 노출 없음 | 켜져 있는데 노출 0 |
| 클릭률 낮음 | 노출 1만 이상, 클릭률 < 0.2% |
| 전환율 낮음 | 클릭 200 이상, 전환율 < 1% |
| 확대 후보 | ROAS ≥ max(손익분기, 목표) × 1.3 |

### AI 스마트 (캠페인 화면 위쪽 접이식 상자)
AI 스마트 광고와 나머지 캠페인의 광고비 비중·ROAS·클릭률·전환율·CPC 비교와 제안.
AI 스마트에서 바꿀 수 있는 것은 일예산·목표 ROAS·특정 상품 제외·제외 키워드입니다 (키워드·입찰가는 쿠팡 자동 운영).

### 키워드
1. 광고센터 → 광고보고서 → 「매출 성장 광고 보고서」에서 기간·캠페인을 골라 보고서를 만들고 엑셀을 내려받습니다.
2. 파일을 올리면 캠페인·키워드별로 합산해 낭비(광고비 3천원 이상, 전환 0)·손익분기 미달·우수를 표시합니다.
3. 「제외 키워드 추가안 만들기」 → 수정 사항에 추가됩니다.

### 키워드 트렌드 (인기 키워드)
WING 「쿠팡 인기 상품 검색」(wing.coupang.com/tenants/rfm-ss/coupang-trends/popularity-search) 데이터를 사용합니다. 먼저 「지금 점검」으로 상품 점검을 실행해야 합니다 (카테고리 정보는 0.5.2부터 저장).
1. 내 상품 카테고리 중 조회할 카테고리를 고릅니다 (기본: 판매 중 상품이 많은 5개, 최대 15개).
2. 「인기 키워드 조회」 → 카테고리별 인기 검색어 10개와, 키워드마다 판매량순 상위 60개 상품의 조회수·가격·리뷰·**내 상품 순위**를 확인합니다 (키워드당 약 2초).
3. 「추천」 보기는 내 상품이 순위 밖·하위권이거나 제외 키워드로 막혀 있는 인기 키워드를 수요 큰 순으로 보여 줍니다 → 상품명·검색어 태그 보강, 수동 광고 키워드 검토에 사용하세요.
- 쿠팡 보안 차단을 피하려고 키워드당 약 4초 간격, 한 번에 60개까지 조회하고 24시간 안에 조회한 키워드는 재사용합니다. 차단되면 40초 쉬고 1번 재시도한 뒤 중단하며, 지금까지 결과는 저장됩니다 (30분쯤 뒤 다시 조회하면 남은 키워드만 조회).
- 조회수는 쿠팡이 제공하는 28일 조회수 구간(예: 1만~2만)입니다. 1,000 미만은 0으로 계산합니다.

### 광고 중인 문제 상품
광고 점검 때 상품 점검에서 문제가 있는 옵션(노출 제한·품절·아이템위너 아님·속성 오류)의 광고비를 함께 조회합니다. 「광고 → 캠페인」 위쪽 상자와 「상품 → 문제 목록」의 「광고 중 · 광고비」 표시로 확인하고, 상품 문제를 해결하거나 캠페인에서 그 상품을 빼세요. 광고가 많은 AI 스마트는 광고 목록을 몇 번의 광고 점검에 나눠 모읍니다 (7일 저장).

### 캠페인별 마진율 · 변경 효과 · 알림
- 캠페인 카드의 「마진율」에 값을 넣으면 그 캠페인만 다른 손익분기 ROAS를 씁니다 (비우면 전체 마진율).
- 「수정사항 → 적용 기록 · 변경 효과」: 적용 후 7일이 지나고 기간 「최근 7일」로 광고 점검하면 적용 전후 하루 평균(광고비·매출·ROAS·이익)을 비교해 개선/악화/변화 없음을 표시합니다.
- 설정 「매주 광고 점검 알림」: 마지막 광고 점검 후 7일이 지나면 알림.

### 수정 사항 (⚠ 실제 광고 설정 변경)
- 변경안 기준 (「변경안 기준」에서 조정, 자세한 내용은 docs/광고-변경안-기준.md): 목표 ROAS ↔ 노출 반비례, 일예산은 예산 소진율 90% 이상일 때만 조정, 캠페인당 한 번에 하나·조금씩, 새 캠페인 14일·변경 후 7일은 변경하지 않음. 전환 0(광고비 3만원 이상)·ROAS 100% 미만 → OFF / 손익분기 미달 → 목표 ROAS 한 단계 상향 / 효율 좋음 → 예산 소진 시 일예산 증액, 예산 남으면 목표 ROAS 한 단계 하향.
- 변경안 만들기: 「진단 결과로 변경안 만들기」 / 키워드 탭의 제외 키워드 추가안
- **선택 항목 적용**: 일예산·목표 ROAS·ON/OFF만, 확인 창에서 동의한 경우에만 적용합니다. 적용 후 다시 조회해 실제 반영을 확인하고 결과를 기록합니다.
- 제외 키워드는 자동 적용하지 않습니다. 「복사 + 편집 화면 열기」로 광고그룹 편집 화면의 「키워드 제외」에 붙여넣고 저장하세요.
- 처음에는 중요하지 않은 캠페인 1개로 적용해 보고 광고센터에서 반영을 확인하세요.

광고센터 데이터는 외부 공개·제3자 제공이 금지되어 있어 이 PC에만 저장됩니다.

## 수집 방식 · 소요 시간
1. 상품 목록 + 노출 상태: 50개 상품당 2회 호출 (상품 1,000개 ≈ 1분)
2. 상세 정보: 판매중 상품 1개당 1회 호출 (판매중 상품 200개 ≈ 5분)
설정에서 「상세 정보 수집」을 끄면 빠르지만 노출상품ID·옵션 분리·누락 속성은 확인할 수 없습니다.

## 안전 원칙
- 읽기 전용: WING 상품 조회/수정 화면이 사용하는 상품 검색 엔드포인트만 호출하며, 수정·제출하지 않습니다.
- 페이지 간 1.5초 대기, 오류 발생 시 즉시 중단 (단시간 대량 오류 요청으로 인한 IP 차단 방지).
- 데이터는 이 PC의 Chrome(chrome.storage.local)에만 저장되며 외부 서버로 전송하지 않습니다.
