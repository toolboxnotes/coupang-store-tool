# coupang-store-tool 서버 버전 (보류)

> 2026-11-20 보류 결정: Open API로는 카탈로그 매칭 분리·결합과 광고 데이터를 다룰 수 없고, 주요 기능은 확장 프로그램이 이미 담당합니다. 24시간 모니터링이 꼭 필요해지면 다시 검토합니다.

쿠팡 Open API 기반으로 PC가 꺼져 있어도 24시간 상품 상태를 모니터링하고 정기 리포트를 보냅니다.

- 대상 기능: 상품 동기화(A1), 노출 오류 진단(A2)·수정(A3), 일일 리포트(A7)
- 필요 사항: Open API 키(자체개발), 고정 IP 서버(IP 화이트리스트 등록), 키 180일마다 재발급
- 착수 시점: 보류 (필요해지면 재검토)
