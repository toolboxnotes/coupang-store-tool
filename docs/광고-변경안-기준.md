# 광고 변경안 기준 (v0.7.3)

「광고 → 수정사항 → 진단 결과로 변경안 만들기」가 어떤 기준으로 변경안을 만드는지 정리한 문서입니다.
쿠팡 광고 운영 가이드와 실무 자료(2026-11 조사)를 바탕으로 했습니다.

## 1. 쿠팡 광고의 동작 원리 (조사 결과)

| 항목 | 내용 |
|---|---|
| 목표 ROAS ↔ 노출 | 반비례. 목표 ROAS를 높이면 구매 가능성이 높은 고객에게만 노출(노출·광고비 감소, 효율 상승), 낮추면 노출이 넓어짐. 너무 높으면 노출이 거의 없음 |
| 최적화(학습) 기간 | 자동 운영 광고는 7~14일 동안 상품·키워드를 학습. 이 기간의 잦은 ON/OFF, 일예산·목표 ROAS 수정, 일예산·목표 ROAS 동시 수정은 피해야 함 |
| 손익분기 ROAS | 판매가 ÷ (판매가 − 원가 − 쿠팡 수수료) × 100 = 100 ÷ 마진율. 이보다 낮으면 광고로 팔수록 손해 |
| 일예산 | 하루 종일 광고가 돌 수 있을 정도로. 예산을 다 쓰지 않는 캠페인은 예산을 바꿔도 노출이 달라지지 않음 |
| 효율 저하의 원인 | 설정보다 상품(아이템위너·재고·가격·리뷰·썸네일·상세페이지)과 엉뚱한 검색어인 경우가 많음 → 검색어 보고서로 제외 키워드, 마진 낮은 상품 제외 |
| 점검 주기 | 최소 주 1회 클릭률·전환율·ROAS 점검 |

## 2. 변경안 판단 순서

캠페인마다 **변경안은 1개만** 만듭니다 (일예산과 목표 ROAS를 동시에 바꾸지 않음).

0. **제외** (변경 안 함, 이유 표시)
   - 꺼진 캠페인
   - 시작한 지 14일 미만 (최적화 기간)
   - 최근 7일 안에 이 도구로 변경을 적용한 캠페인
   - 기간 광고비 1만원 미만, 전환 주문 5건 미만 (데이터 부족)
1. **전환 0 + 광고비 3만원 이상** → OFF
2. **ROAS 100% 미만** (광고 매출 < 광고비) → OFF 후보
3. **손익분기 미달**
   - 목표 ROAS < 손익분기 → 목표 ROAS **한 단계 상향** = max(현재 목표, 실제 ROAS) × 1.2, 손익분기 상한
   - 실제 ROAS가 손익분기의 50% 미만이면 → 제외 키워드·상품 제외 검토도 안내
   - 목표 ROAS가 이미 손익분기 이상 → 예산 소진율 90% 이상이면 일예산 20% 축소, 아니면 변경 없이 검색어·상품 점검 안내
4. **효율 좋음** (ROAS ≥ max(손익분기, 목표) × 1.3)
   - 예산 소진율 90% 이상 → 일예산 20% 증액 (예산이 노출을 막고 있음)
   - 예산 소진율 70% 미만 → 목표 ROAS 한 단계 하향 (노출 확대), 하한 손익분기 × 1.15
   - 그 사이 → 유지
5. **켜져 있는데 노출 0**
   - 상품 문제(품절·아이템위너 아님·검수 실패) → 안내만
   - 목표 ROAS > 손익분기 → 목표 ROAS 한 단계 하향 (하한 손익분기)

예산 소진율 = 기간 광고비 ÷ (일예산 × 기간 일수). 기간 중 일예산이 바뀌었으면 오차가 있습니다.

## 3. 조정 가능한 값 (「변경안 기준」)

| 값 | 기본 |
|---|---|
| 목표 ROAS 1회 조정 폭 | 20% |
| 일예산 1회 조정 폭 | 20% |
| 판단 최소 전환 주문 | 5건 |
| 변경 후 대기 | 7일 |
| 새 캠페인 최적화 기간 | 14일 |

마진율은 광고 탭에서 입력합니다: (판매가 − 원가 − 쿠팡 수수료 − 배송비) ÷ 판매가. 손익분기 ROAS가 700% 이상이면 확인 안내가 나옵니다.
