# coupang-store-tool 개발 목록

범위: 상품 카탈로그 상태 + 광고. (주문/배송/반품·교환/물류/정산 제외)

## 핵심 사실
- 쿠팡 Open API는 「카탈로그 매칭관리」「상품구성」「자동가격조정」을 지원하지 않음 → 분리/결합은 WING 화면에서만 가능
- 광고센터는 공개 API 없음 → 화면 읽기 / 보고서 다운로드
- 개발 계정은 상품 0개·캠페인 0개 → 실제 데이터 검증용 계정 필요

## 두 가지 제품 (별도 개발, 확장 우선)
1. **확장 프로그램** — 로그인된 WING/광고센터 화면에서 데이터 읽기, Chrome이 켜져 있으면 정기 점검. 수정은 「엑셀 대량 수정」 파일 생성 또는 화면 자동 입력 후 사용자가 직접 제출.
2. **서버 버전 (보류, 2026-11-20)** — Open API 기반, 24시간 모니터링. 매칭 분리/결합·광고는 지원 불가 → 확장이 주요 기능을 담당하므로 보류.

## A. 상품 (핵심)
- A1 상품 동기화: 등록상품ID / 노출상품ID / 옵션ID / 속성 / 상태, 일일 스냅샷
- A2 노출 오류 진단: 노출제한·노출낮음·상품정보 수정필요 + 카테고리 필수 항목 대조
- A3 노출 오류 수정: 엑셀 대량 수정 파일 생성 / 화면 자동 입력 (서버 버전은 API 상품 수정)
- A4 타사 매칭 감지: 노출상품ID 변경, 아이템위너 상실 → 알림
- A5 분리 요청: 옵션ID·등록상품ID·업체코드·차이점 증빙 정리 → 온라인 문의 자동 입력, 사용자가 제출
- A6 옵션 분리 → 결합: 자사 동일 상품이 여러 노출상품ID로 나뉜 경우 결합 요청
- A7 일일 상품 점검 리포트

## B. 광고 (확장 프로그램)
- B1 데이터 수집: 매출 성장 대시보드, 광고보고서, 상품 기회 탐색, 추천, 변경 이력
- B2 분석: ROAS, 전환 없는 키워드, 검색/비검색 비중, 손익분기 ROAS
- B3 수정 제안 (2단계에서 확인 후 실행)
- B4 공지 모니터링: WING 공지, 광고 정책, 개발자센터 공지

## 진행 상황 (v0.7.2)
| 항목 | 상태 |
|---|---|
| A1 상품 동기화 | ✅ 목록 + 노출 상태 + 상세(노출상품ID) |
| A2 노출 오류 진단 | ✅ 쿠팡 판정 기준, 상세 사유 표시 |
| A3 노출 오류 수정 | 🔶 WING 상품 수정 화면 바로가기 + 상세 사유 표시 (속성값 자동 입력은 판매자 확인 필요로 보류) |
| A4 타사 매칭 감지 | ✅ 아이템위너 타사/자사 구분, 노출상품ID 변경 |
| A5 분리 요청 | ✅ 온라인 문의 자동 입력 (제출은 직접) |
| A6 옵션 결합 | ✅ 분리 감지 + 온라인 문의 자동 입력 (제출은 직접) |
| A7 일일 리포트 | ✅ 패널·CSV·알림 |

## 광고 진행 상황 (v0.7.2)
| 항목 | 상태 |
|---|---|
| B1 광고 데이터 수집 | ✅ 캠페인 목록·캠페인별 성과·일별 합계 (대시보드 수치와 일치 확인) |
| B2 분석 | ✅ 캠페인 단위 + AI 스마트 비교 + 키워드(보고서 업로드)·제외 키워드·추천 CPC |
| B2 인기 키워드 | ✅ WING 쿠팡 인기 상품 검색: 내 카테고리 인기 검색어 + 키워드별 상위 상품·내 상품 순위 + 제외 키워드 충돌 |
| B3 수정 | ✅ 변경안(진단·키워드·CSV 업로드) → 동의 후 적용(일예산·목표 ROAS·ON/OFF) + 반영 확인, 제외 키워드는 복사+편집 화면 |
| B4 공지 모니터링 | ⬜ |

## 일정
- 확장: 1단계 ✅ → 2단계 ✅ → 3단계 ✅ (캠페인·AI 스마트·키워드·수정) → 4단계 B4 공지 모니터링
- 서버: 보류 (필요해지면 재검토)
